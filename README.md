# ระบบจัดการข้อมูลนักศึกษา

โปรแกรมภาษา C ขนาดเล็กที่ใช้เมนูสำหรับจัดการข้อมูลนักศึกษา สามารถเพิ่มหรือลบข้อมูล แสดงรายชื่อ ค้นหาข้อมูล เรียงลำดับตามคะแนน และดูสถิติคะแนนได้ นักศึกษาแต่ละคนมีรหัส ชื่อ คะแนน และเกรดที่คำนวณจากคะแนน

โปรแกรมรองรับข้อมูลนักศึกษาได้สูงสุด 100 คน ข้อมูลจะถูกเก็บไว้ในหน่วยความจำและจะหายไปเมื่อออกจากโปรแกรม

## วิธีใช้งาน

คอมไพล์ไฟล์ `src/main.c` ด้วยคอมไพเลอร์ภาษา C บน Windows แล้วเรียกใช้โปรแกรม ตัวอย่างการใช้ MinGW:

```sh
gcc src/main.c -o student-management.exe
student-management.exe
```
